# Projeto: Caso Símile AI - Responsabilidade Civil e Inteligência Artificial

**Finalidade:** Demonstrar o fluxo de RAG manual e auditoria humana na construção de teses jurídicas envolvendo falhas de Inteligência Artificial generativa e violação de direitos da personalidade.
**Público:** Professores, estudantes de direito e revisores técnicos.
**Limites:** Este é um caso estritamente fictício para fins acadêmicos. As saídas não substituem parecer jurídico oficial. Não há uso de dados reais.
**Critérios de Aceitação:** O repositório deve conter sanitização de dados, restrição estrita a fontes fornecidas (CDC, CC e CF), trilha de auditoria contra alucinações e registro explícito de revisão humana com decisões de manter/corrigir/excluir.
**Instruções de Navegação:** 
1. Leia `entrada/relato_bruto.md` para entender o problema.
2. Veja `docs/limites_e_sigilo.md` para as regras de privacidade.
3. Siga para `prompts/` e `evidencias/` para acompanhar o processamento da IA.
4. O resultado final está em `entrega/orientacao_inicial.md`.
